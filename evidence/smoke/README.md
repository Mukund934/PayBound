# Smoke run — NOT a result

Six items, run once, to prove the runner works end to end. It is committed
because it is real output from the real pipeline against the real model, and
deleting it would make the pipeline unverifiable at this commit.

**It is not a measurement and no number in it may be quoted.** The corpus is 150
items; this is six. The rule-of-three upper bound on its three attack trials is
about 100%, which is the honest way of saying three trials prove nothing — and
the fact that the formatter prints that automatically is the point of the
exercise.

The published run lives in `evidence/<run_id>/` and is produced under
`PREREG.md`.
